# 🛒 Meesho App - Manual Testing Project

This is an end-to-end manual testing project performed on Meesho Android App & Website. The project covers complete STLC from Requirement Analysis to Test Closure.

### 🔗 Project Link
Live App Tested: Meesho

### 📋 Project Overview & Scope
- **Objective:** To validate core functionalities of Meesho like Login, Search, Add to Cart, Checkout & Address Management.
- **Testing Types Performed:** Functional Testing, UI Testing, API Testing (Postman), Retesting, Regression Testing.
### 📂 Repository Structure
- `/Test Documents` - Test Scenario, Test Cases, RTM, Bug Report, Test Summary Report
- `/Screenshot` - All bug evidences (JPG, PNG, MP4)
- `/Postman` - Postman collection for API testing
